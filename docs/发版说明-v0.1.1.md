# v0.1.1

在 v0.1.0 之后的第一个更新。**需要 Node.js 22.13 或更新版本**（房间的存储换成了 Node 自带的 `node:sqlite`，Node 20 里没有）；版本不够时，启动脚本会直接说明。

## 新增

- **左侧一栏两档**：项目列表和房间点一下互相切换，带「走进房间」的过渡动画；别的项目里有人等你时，返回按钮上有数字。
- **流程视图**（只读）：群聊旁边多一个「流程」，把一件事从谁提出、谁接手到谁验收画成图；摘要 bot 会给每个块起短名。
- **深色主题重做**：冷调的极光背景（浏览器按你的屏幕实时画，可在设置里开「缓慢流动」）、毛玻璃的输入框、提示条和 @ 胶囊。
- **对话左边的刻度尺**：平时是冷灰蓝，鼠标靠近的几根变白变长，放音乐时按声音从深蓝渐变到青蓝、紫色（需要 Linux 且有 `parec`）。
- **别的项目做完时会提示**：页面顶部出一条毛玻璃胶囊，几秒后自己消失；可选的桌面通知。
- **席位档案与交接单**：给席位写职责、长期记忆，换脑时带上交接单。
- **默认全部权限**：开新会话时可以勾，干活时可以临时收回这一次。
- **「正在做」的气泡**末尾是停止按钮；右栏待办换成了毛玻璃卡片。
- 会话内搜索的结果可以跳到更早的消息，中间缺的会有「点这里补上」。

## 改进

- 存储从一个 JSON 文件换成 SQLite（WAL），重启不丢队列。
- 给托管 agent 的提示词瘦身：每次叫醒少带约 700 字，会话压缩后自动再给全套规矩。
- 取消 agent 之间自动接力的次数上限（要停一条线，让席位说「本轮结束」或你插话）。
- 刻度尺律动、点「回复」的展开动画、切换项目都更跟手。

## 修复

- 摘要卡在「正在跑」、点停止说「没在跑」：长对话的摘要提示词超过系统单个参数的 128KB 上限，现在按字节限长，启动失败会清理并在群里说明。
- 桥把「等回答超过 5 分钟」误报成「房间没开」。
- 席位中途在群里发言后，它的「正在做」气泡被藏掉。
