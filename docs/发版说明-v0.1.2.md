# v0.1.2

v0.1.1 之后的更新。仍需 Node.js 22.13 或更新版本。从这一版起可以用 `npm run update` 更新。

## 新增

- **两层页面，平时只留对话和「等你定」**：不常用的功能收进「高级」；第一次打开只问一句话就能开始。
- **前台**：一个跨项目的房间，值班的 AI 能只读看所有项目的进展和等你处理的事；「等你定」列出所有项目里等你拍板的事。
- **前台代签**：全房间一个开关，复验过、不需要你本人看的待办房间自己收；整批卡片里「只能你签」的一行可以直接点「通过」，点完会说明还剩几件；带着问题收下的有 14 天清单，可以重开。
- **「进展」视图**：一件事一行；每条回复有一句话摘要，对话里先显示摘要。
- **请验收时先复验**：另一个席位先检查一遍；没过的改好后会再查（最多重查两次，再不过交给你定）；排太久或撞上额度的检查会自动换人，不会一直排着。
- **停了自己接着做**：席位停满 5 分钟还欠着活，房间会自己叫它；重启后继续。网络错误自动重试，叫醒时带上还欠的事。
- **你回来时的一张卡**：离开半小时以上再回来，「你不在的这段时间」列出各项目发生了什么。
- **摘要到期时房间自己找人写**，不再每次弹卡问你。
- **每天自动备份数据库**：保存在 `data/backups/`，保留最近 7 份；出事时 `npm run restore` 一条命令找回（找回前会先另存一份当前数据库）。
- **日常命令**：`npm run setup` 装桌面图标和开机自启（Linux），`npm run stop` 停止（有 AI 在干活时会先拦住），`npm run update` 更新。启动时依赖清单有变化会自动 `npm install`。
- 没 @ 人的话默认叫最后说话的 AI；有事等你时可以推送到手机（可选，默认关）；Codex 的权限请求接到房间里批；文字大小可调（小、标准、大、特大）。

## 改进

- 同一件事只出一张卡，要紧的排前面，事情多了自动收起。
- 页面只在看得出变化时才刷新：在线席位的心跳不再让整间房重画，空闲时页面不再卡顿。
- 做完超过 48 小时的待办不再进主快照，房间更轻。
- 界面用词更短更直白。
- README 新增「并坐会改你电脑上哪些东西」，列出写入的文件、改动的 AI 配置（改前自动备份）和读额度时的联网范围。

## 修复

- AI 说完最后一句话却没被认出已结束，席位一直显示「在做」。
- 会话中途出错（如令牌过期）后卡死不报。
- 新开会话没拿到会话 id 时不说原因。
- 会话压缩后多出的噪音消息。
