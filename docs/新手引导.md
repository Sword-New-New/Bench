# 并坐 新手引导

写给第一次用的人（jinbao 这样的使用者）。给 agent 看的协议在 `PROTOCOL.md`，改代码的人看 `MAINTENANCE.md`，这份只讲怎么用。

## 一句话

并坐是你这台电脑上的一间「会议室」：把 Claude、GPT、Grok、Gemini 等多个 AI 请进同一个房间，在网页上对话、派待办、看进度。每个项目一间房，互不串。

## 第 1 步：打开房间，说一句想做什么

在仓库目录运行 `./start.sh`（Windows 双击 `start.bat`；装了桌面图标就双击「并坐」）。它会检查并按需更新依赖、启动房间，并用带口令的地址替你打开浏览器。只在本机可访问，这是故意的：房间能在你电脑上执行命令。第一次打开会慢几秒，属正常。

> 别自己在浏览器里敲 `http://127.0.0.1:4399`：那样打开的页面没有口令，发消息会被拒。已经开着的房间，用 `npm run open` 重新打开一次就好。想停掉、更新或装桌面图标见下面「日常管理」。

第一次打开时，页面只问一句「你想做点什么？」：

1. 写一句话，比如「给我的小店做一个网站，要有商品列表和购物车」。
2. 下面两行房间已经替你选好：**谁来做**是这台电脑上装好的 AI（按 Claude、GPT、Gemini、DeepSeek、Grok 的顺序挑第一家装了的），**放在哪**是桌面上新建一个以这句话开头几个字命名的文件夹。想换就点各自的「换一个」。
3. 点「开始」。房间会把这家 AI 接好、建好文件夹和项目、开好第一个 AI，再把你这句话交给它。之后就是平常的页面，它会在对话里回你。

一家 AI 都没装时，这一屏会告诉你装哪个最省事；装好后点「装好了，再看一次」。

想自己一项项设置（项目名、接哪几家、模型、工作目录），点右上角「更多设置」，就是下面第 2、3 步讲的完整页面。

## 第 2 步：认识页面

| 位置 | 是什么 |
| --- | --- |
| 左栏「入口」 | 各种 AI，每家一行，下面每个会话（席位）一行。点头像或名字就是 `@` 它。名字右边的小圆环是账号额度，点圆环或箭头展开看客户端、各条额度、速度和「开新会话」。 |
| 中间「对话」 | 聊天记录，你和 AI 的话、提问卡片、权限确认、附件都在这里。底部是输入框。 |
| 右栏「待办」 | AI 建的待办和步骤，你在这里验收。 |
| 左上角项目名 | 切换、新建、编辑项目（名字、项目目录）。 |
| 右上角 | 在线/在做的人数、设置（深浅色、更多设置收在「高级」里）、「接入 AI」。 |

手机或窄屏时，三栏变成底部的三个标签。

## 第 3 步：再请几个 AI 进来

第 1 步已经替你请好了第一个。想再加，点右上角「接入 AI」：最省事的是在「房间替你开一个」里直接选客户端；如果要接已有会话，展开「高级」按三步走：

1. 选客户端。
2. 写入客户端配置（每家一次，以后换项目也不用重做）。
3. 在它会话里发那句入座。

入座成功后，左栏就能看到它的头像和状态。

> 注册这一步会往那个 AI 自己的配置文件里加一条 MCP 服务（`~/.claude.json`、`~/.codex/config.toml` 之类），并坐自己的数据也存在 `data/` 目录。完整清单见 README 的 [并坐会改你电脑上哪些东西](../README.md#并坐会改你电脑上哪些东西)。

## 第 4 步：跟它说话

- 在输入框写字，按「发给」选对象（也可以直接写 `@名字`）。点「@所有人」叫全部。
- 点左栏头像会把 `@名字` 填进输入框。
- 回形针可以附文件或文件夹；也可以直接粘贴图片、把文件拖进来。
- 「发给」下面的标签可以拖动排序。
- 回复 AI 的某条消息，发出去就会叫醒它，不用再写 `@`。

AI 干活的时候：

- 对话底部有一张「正在做」卡片，实时显示它在做哪一步。
- 点「查看过程」能看它的完整步骤。
- 左栏它的席位菜单（鼠标移到那一行，右边出现「…」）里可以「单独说…」（让它先停下回你，回完接着做）、「停下这次」。

## 第 5 步：待办与验收

你让 AI 做新功能，它会先在右栏建一条待办，拆成几步，做一步标一步。做完后它请你验收。

- 「验收」那一步只有你能点：**通过**，或**打回**（必须写理由，负责人会被叫醒返工）。
- 一个待办只有一个负责人，别人不会重复做。

## 第 6 步：AI 会来问你

- **提问**：AI 需要你拍板时，对话里出现一张问题卡片，点选项或自己写答案。
- **权限**：AI 要跑没放行的命令时，输入框上方出现确认条：「允许一次」「本轮全允」「拒绝…」。10 分钟没人回会自动拒绝。
- AI 也可以主动申请「完整权限」，同意后只管这一次叫醒，结束自动收回。你也可以在它运行中的卡片上随时给或收回。

## 第 7 步：AI 的汇报里有图、视频、音频

图片点开可放大、旋转、保存；视频和音频直接在消息下面播放，可拖进度，同时只播一个。

## 常用小功能

- **撤回**：只能撤自己的消息，撤回后原文真的删除，AI 也看不到；可「重新编辑」。
- **房间摘要**：聊得太长时房间会提醒你找一个 AI 写房间摘要，新来的 AI 靠它快速跟上。
- **重新叫醒**：服务器重启把一次叫醒打断了，会出现「重新叫醒」按钮。
- **深浅色**：设置里切换。
- **调试菜单**：开发模式下右上角有，可以演示「正在做」卡片等效果，不会写进房间。

## 日常管理：装图标、停止、更新

- **装好桌面图标和开机自启（Linux）**：在项目目录运行 `npm run setup`（需要先装好 `tmux`），会自动装好应用菜单里的「并坐」图标，并问你要不要登录后自动启动。不想自启可加 `-- --no-autostart`，以后不想要了运行 `npm run setup -- --remove` 就能卸掉。Windows 请直接双击 `start.bat`，或手动把它的快捷方式放到桌面、`shell:startup` 启动文件夹。
- **停止并坐（Linux / macOS）**：在项目目录运行 `npm run stop`，不管之前是用 `./start.sh` 还是桌面图标起的都会停掉。如果当时有 AI 正在干活，命令会先列出是谁并停下来提醒你；确认要强行打断再加 `-- --force`（即 `npm run stop -- --force`）。Windows 请切回开着房间的窗口按 `Ctrl+C` 或关闭窗口。
- **更新到最新版**：运行 `npm run update`。只有在工作区没有未提交改动时才会拉最新代码并自动装好新依赖；**更新后不会自己重启**，按提示先 `npm run stop` 再重开就会生效。平常用 `./start.sh`、桌面图标或 `start.bat` 启动时，只要依赖清单变了也会自动先装好再开。

## 常见问题

- **页面打不开 / 提示房间没有打开**：服务没启动，运行 `npm run dev`。
- **AI 头像是灰的（离线）**：它超过 40 秒没报进度。会话关了就重新入座。
- **@ 了没反应**：看左栏那一家名字旁边有没有黄字。写着「缺唤起命令」「未安装」或「离线 · 未报会话」就是叫不醒：前一种点右上角设置 › 「高级」 › 「唤起命令…」检查，后两种装好客户端或让它重新入座。没有黄字说明叫得醒，再看输入框下面有没有提示「这句不会叫醒谁」（名字要和席位名一字不差，后面留空格）。
- **页面样式不更新**：停服务，删 `.next/dev`，再启动。
- **几个 AI 同时改同一批文件互相覆盖**：开新会话时展开「高级」选「新分支」，各用各的分支。
- **删项目**会把里面所有席位、对话、待办一起删掉，操作前确认。

## 五分钟上手路线

1. `npm run dev`，打开页面。
2. 「接入 AI」里接一个你已有的 AI（或让房间替你开一个）。
3. 输入框选「发给」它，写：「介绍一下你自己，然后建一个待办：给项目写个 README 草稿」。
4. 看「正在做」卡片和右栏待办，点「查看过程」。
5. 它请验收后，在右栏点通过或打回。

到这里就会用了。
