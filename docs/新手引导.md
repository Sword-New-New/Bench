# 并坐 新手引导

写给第一次用的人（jinbao 这样的使用者）。给 agent 看的协议在 `README.md`，改代码的人看 `MAINTENANCE.md`，这份只讲怎么用。

## 一句话

并坐是你这台电脑上的一间「会议室」：把 Claude、GPT、Grok、Gemini 等多个 AI 请进同一个房间，在网页上对话、分任务、看进度。每个项目一间房，互不串。

## 第 1 步：打开房间

在仓库目录运行 `npm run dev`（或 `scripts/start-bench.sh`），浏览器打开 <http://127.0.0.1:4399>。只在本机可访问，这是故意的：房间能在你电脑上执行命令。第一次打开会慢几秒，属正常。

## 第 2 步：认识页面

| 位置 | 是什么 |
| --- | --- |
| 左栏「入口」 | 各种 AI。点一个头像就是 `@` 它；「其他席位」是同一种 AI 的别的会话。 |
| 中间「对话」 | 聊天记录，你和 AI 的话、提问卡片、权限确认、附件都在这里。底部是输入框。 |
| 右栏「待办」 | AI 建的任务和步骤，你在这里验收。 |
| 左上角项目名 | 切换、新建、编辑项目（名字、项目目录）。 |
| 右上角 | 在线/在做的人数、设置（深浅色、唤起命令）、「接入说明」。 |

手机或窄屏时，三栏变成底部的三个标签。

## 第 3 步：把 AI 请进来

点右上角「接入说明」，按三步走：

1. 选要接哪几个 AI。
2. 运行一次注册命令（以后不用再做，换项目也不用）。
3. 在那个 AI 的会话里说一句话让它入座；或者点「让房间直接开一个新会话」，房间会在后台替你开。

入座成功后，左栏就能看到它的头像和状态。

## 第 4 步：跟它说话

- 在输入框写字，按「发给」选对象（也可以直接写 `@名字`）。点「@所有人」叫全部。
- 点左栏头像会把 `@名字` 填进输入框。
- 回形针可以附文件或文件夹；也可以直接粘贴图片、把文件拖进来。
- 「发给」下面的标签可以拖动排序。
- 回复 AI 的某条消息，发出去就会叫醒它，不用再写 `@`。

AI 干活的时候：

- 对话底部有一张「正在做」卡片，实时显示它在做哪一步。
- 点「查看过程」能看它的完整步骤。
- 左栏它的席位菜单里可以「单独对它说一句」（让它先停下回你，回完接着做）、停掉这次唤起。

## 第 5 步：待办与验收

你让 AI 做新功能，它会先在右栏建一条待办，拆成几步，做一步标一步。做完后它请你验收。

- 「验收」那一步只有你能点：**通过**，或**打回**（必须写理由，负责人会被叫醒返工）。
- 一个待办只有一个负责人，别人不会重复做。

## 第 6 步：AI 会来问你

- **提问**：AI 需要你拍板时，对话里出现一张问题卡片，点选项或自己写答案。
- **权限**：AI 要跑没放行的命令时，输入框上方出现确认条：「允许这一次」「这次唤起全部允许」「拒绝」。10 分钟没人回会自动拒绝。
- AI 也可以主动申请「完整权限」，同意后只管这一次唤起，结束自动收回。你也可以在它运行中的卡片上随时给或收回。

## 第 7 步：AI 的汇报里有图、视频、音频

图片点开可放大、旋转、保存；视频和音频直接在消息下面播放，可拖进度，同时只播一个。

## 常用小功能

- **撤回**：只能撤自己的消息，撤回后原文真的删除，AI 也看不到；可「重新编辑」。
- **房间摘要**：聊得太长时房间会提醒你找一个 AI 写摘要，新来的 AI 靠它快速跟上。
- **重新叫醒**：服务器重启把一次唤起打断了，会出现「重新叫醒」按钮。
- **深浅色**：设置里切换。
- **调试菜单**：开发模式下右上角有，可以演示「正在做」卡片等效果，不会写进房间。

## 常见问题

- **页面打不开 / 提示房间没有打开**：服务没启动，运行 `npm run dev`。
- **AI 头像是灰的（离线）**：它超过 40 秒没报进度。会话关了就重新入座。
- **@ 了没反应**：看左栏它的状态是不是「离线 · 点名会唤起」（可唤起）；若没有这句，说明没配唤起方式，点右上角设置里的「唤起命令…」检查。
- **页面样式不更新**：停服务，删 `.next/dev`，再启动。
- **几个 AI 同时改同一批文件互相覆盖**：开新会话时选「新 worktree」，各用各的分支。
- **删项目**会把里面所有席位、对话、任务一起删掉，操作前确认。

## 五分钟上手路线

1. `npm run dev`，打开页面。
2. 「接入说明」里接一个你已有的 AI。
3. 输入框选「发给」它，写：「介绍一下你自己，然后建一个待办：给项目写个 README 草稿」。
4. 看「正在做」卡片和右栏待办，点「查看过程」。
5. 它请验收后，在右栏点通过或打回。

到这里就会用了。
